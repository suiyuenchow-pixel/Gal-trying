# Gal-trying

《晴天以后，靠窗第二排》：原创校园恋爱视觉小说，剧本重写版 1.1。

## 游玩

下载本仓库 ZIP 并完整解压，打开 `index.html` 即可离线游玩。推荐使用 Edge 或 Chrome，音乐在点击开始后播放。

约 1.56 万中文字符，四条人物线、八种结局；包含 16 张透明立绘、10 张背景、4 张事件 CG、封面、5 首合成器乐、雨声与存读档等功能。没有配音。

## 文件与存档

- `scenario.js`：当下第一人称剧本、选择与分支。
- `director.js`：场景与演出配置。
- `app.js`、`audio.js`：运行器、存档、菜单与声音。
- `assets`：全部本地素材。
- `PLAYER_GUIDE.txt`：操作说明。

存档保存在玩家本机浏览器，不会自动同步设备。剧本 1.1 使用独立存档区，不沿用旧版本页码。

本仓库仅包含可独立运行的网页版本，不包含开发依赖、桌面运行时和旧项目。美术为 AI 辅助生成，音乐为原创程序化合成；未包含第三方商业游戏素材。
